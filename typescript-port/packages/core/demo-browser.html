ℹ️ About This Demo

This browser demo shows the Osvauld authentication system working with:

  • BIP39 Mnemonics: 12-word recovery phrases
  • AES-GCM Encryption: Your password encrypts the mnemonic
  • IndexedDB Storage: Data stored locally in your browser
  • Ed25519 Signatures: Secure cryptographic keys
  • Session Management: Token-based authentication

Note: This is running in sandbox mode. All data stays in your browser. Open DevTools → Application → IndexedDB to see the stored data!
